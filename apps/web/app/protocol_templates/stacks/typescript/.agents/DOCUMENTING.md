# TypeScript Documentation

- Describe exported functions, types, discriminated variants, and runtime errors
  with examples that compile under the project's TypeScript configuration.
- State the runtime and module format required by examples, including browser
  APIs, Node APIs, and type-only dependencies.
- Document validation at external boundaries and distinguish optional properties
  from values that explicitly allow `undefined` or `null`.
- Explain promise rejection, cancellation, and resource cleanup where relevant.
- Use existing JSDoc or TSDoc conventions and package scripts. Do not document a
  type assertion as runtime validation.

Reference: [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html).
