# Angular Documentation

- Document component inputs, outputs, content projection, and accessibility
  behavior when they form a reusable UI contract.
- Describe route parameters, guards, lazy loading, and required service providers
  when they affect feature integration.
- Use commands from the actual package scripts and Angular workspace. State
  browser support and the Angular version relevant to examples.
- Explain the lifetime and ownership of shared reactive state and subscriptions.
- Keep screenshots and interaction examples aligned with the rendered component;
  document observable behavior instead of private component implementation.

Reference: [Angular documentation](https://angular.dev/overview).
