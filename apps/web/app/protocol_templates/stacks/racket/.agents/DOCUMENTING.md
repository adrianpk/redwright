# Racket Documentation

- State the supported `#lang`, module paths, exported bindings, and package
  dependencies. Distinguish a file-relative example from an installed collection.
- Document argument and result contracts, exceptional outcomes, parameter
  effects, and resource ownership at public boundaries.
- Explain macro syntax, binding behavior, expansion phases, and relevant error
  locations when these form part of the interface.
- Use Scribble when the project maintains package reference documentation;
  keep documentation dependencies and examples aligned with its package setup.
- Keep executable examples in the language actually used by the module.
  Document any installation, collection-path, or command-line prerequisites.

References: [Racket documentation](https://docs.racket-lang.org/),
[Scribble](https://docs.racket-lang.org/scribble/).
