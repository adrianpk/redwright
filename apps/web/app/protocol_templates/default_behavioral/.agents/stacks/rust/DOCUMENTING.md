# Rust Documentation Overlay

Apply this overlay with `.agents/DOCUMENTING.md` and `.agents/LANGUAGE.md`.

- Keep commands aligned with actual Cargo packages, workspace members,
  binaries, examples, and features.
- Use exact crate, module, trait, struct, enum, function, and feature names.
- Document public ownership expectations, error behavior, feature flags, and
  unsafe invariants.
- Add useful rustdoc to public crate APIs that form a caller-visible contract.
