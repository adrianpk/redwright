# TypeScript Documentation Overlay

Apply this overlay with `.agents/DOCUMENTING.md` and `.agents/LANGUAGE.md`.

- Keep commands aligned with the selected package manager and actual
  `package.json` scripts.
- Use exact exported names, module paths, public package entrypoints, functions,
  types, configuration fields, event shapes, and error contracts.
- Document runtime validation separately from static types at untrusted
  boundaries.
- Add useful API documentation to exports that form a caller-visible contract.
