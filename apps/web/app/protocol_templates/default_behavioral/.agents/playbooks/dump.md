# Dump Procedure

Use this playbook for an authorized user-led knowledge dump.
`.agents/DISCOVERY.md` owns the dump and artifact contracts.

1. Establish the central topic without imposing an interview structure.
2. Let the user transfer context freely while tracking topic shifts,
   contradictions, and derived threads.
3. Maintain `files/raw.md` when the session meets the raw-capture conditions in
   `.agents/DISCOVERY.md`.
4. Briefly steer only when the central topic is lost, a derived thread needs a
   name, a contradiction needs clarification, or a summary pause is necessary.
5. Switch to the quiz procedure only when sustained questioning is needed and
   the user authorizes that mode.
6. Curate the source material into `artifact.md` after it contains enough
   signal.
7. Report the bundle path, central topic, derived threads, open questions, and
   any separately authorized next artifact.
