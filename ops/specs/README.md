# Specifications Ledger

This directory stores specification artifacts produced from alignment cycles.

File types:

- `*-proto-spec.md`: refined working specification derived from discovery and Q&A.
- `*-spec.md`: stabilized, review-ready specification for execution planning.

Rules:

- use dated filenames: `YYYY-MM-DD-<topic>-proto-spec.md` and `YYYY-MM-DD-<topic>-spec.md`
- keep language in English
- update related `ops/plans/*` and `ops/trackers/*` when status changes
