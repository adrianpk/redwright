# What Is RedWright?

RedWright is a runtime agent for software engineering tasks.

Its goal is simple: you describe work in natural language, and RedWright turns that into safe, structured actions in a project workspace.

## Why It Exists

RedWright exists to reduce friction between "idea" and "execution" while keeping control and traceability.

Instead of manually chaining commands, project context switches, and action sequencing, RedWright coordinates those steps through a runtime contract.

## Core Idea

RedWright separates concerns:

- user intent interpretation
- action planning and validation
- bounded execution
- persistence and traceability

This keeps behavior auditable and allows iteration without turning the runtime into an opaque script runner.
