RedWright is a **black-box software factory platform** with a shared semantic core and dual execution modes.

Telegram and local TUI are the current interactive surfaces. A Kanban-driven factory mode extends the same core for structured, sandboxed delivery workflows.

(*) Slack is expected as a later extension after the Telegram path is stable.

## Product Focus

RedWright is designed for software delivery orchestration, not generic chat. The platform supports:

- Interactive mode: low-latency direct operation (Telegram/TUI).
- Factory mode: ticket-driven autonomous flow with role-constrained execution.

## What It Delivers

RedWright provides structured execution from heterogeneous inputs through a Command/Query semantic core, guarded boundaries, persisted evidence, and policy-driven lifecycle control.
